## title: "PinPoint FAQ: Answers to frequently asked questions" description: "Answers to the most common questions about PinPoint, including hotkeys, window limits, multi-monitor support, configuration, and startup."

Answers to the most common questions about PinPoint.

<AccordionGroup>
  <Accordion title="Can I use the Windows key in my hotkey?">
    Yes, you can include the Windows key (**Win**) in your hotkey combination. However, be aware that Windows reserves many Windows-key shortcuts for its own use (for example, **Win\+E** opens File Explorer). If you choose a combination that Windows already claims, it will intercept the keypress before PinPoint can act on it.

    Choose a combination that isn't already used by Windows or other apps. If your hotkey stops working after you set it, try a different combination.
  </Accordion>

  <Accordion title="How many windows can I pin at once?">
    There is no hard limit. You can pin as many windows as you like — each one stays on top until you unpin it individually or use **Unpin All** from the tray menu.
  </Accordion>

  <Accordion title="Does PinPoint work across multiple monitors?">
    Yes. PinPoint pins windows at the Windows API level, so pinned windows stay on top regardless of which monitor they are on. You can move a pinned window between monitors and it will remain Always-on-Top.
  </Accordion>

  <Accordion title="Where is my configuration stored?">
    PinPoint saves your settings to a file called `config.json` at the following path:

    ```text
    %APPDATA%\com.automatalabs.pinpoint\config.json
    ```

    You can paste that path directly into the Windows Explorer address bar to open the folder. You generally do not need to edit this file directly — every setting is accessible from the PinPoint Settings window and saves automatically as you change it.
  </Accordion>

  <Accordion title="How do I stop PinPoint from starting with Windows?">
    There are two ways:

    **Using PinPoint Settings:** Open the PinPoint Settings window and turn off the **Start with Windows** (auto-start) toggle. PinPoint will no longer launch automatically on login.

    **Using Windows Settings:** Go to **Settings → Apps → Startup** and toggle PinPoint off from the list of startup apps.
  </Accordion>

  <Accordion title="Can I change the hotkey to something without Alt?">
    Your hotkey must include at least one modifier key (**Ctrl**, **Alt**, **Shift**, or **Win**). You cannot set a hotkey that is just a single key with no modifier. This is a requirement of the Windows global hotkey API.
  </Accordion>
</AccordionGroup>

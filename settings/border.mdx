When you pin a window, PinPoint draws a colored border around it so you always know which windows are on top. You can change the border color, adjust its thickness, or turn it off if you prefer no visual indicator.

## Border color

To change the border color:

<Steps>
  <Step title="Open Settings">
    Right-click the PinPoint tray icon and choose **Settings**.
  </Step>
  <Step title="Go to the Border section">
    Navigate to the Border section in Settings.
  </Step>
  <Step title="Choose a color">
    Click the color swatch to open the color picker, or type a hex value directly (for example, `#00FFFF` for cyan). The border updates immediately on any currently pinned windows.
  </Step>
</Steps>

## Border thickness

Adjust the thickness slider to make the border thicker or thinner. Changes apply immediately.

## Enabling or disabling the border

Toggle **Enable border** to turn the border on or off. When disabled, PinPoint still pins windows to Always-on-Top — there is simply no visual indicator. The tray icon list still shows all pinned windows.

## How the border works by platform

- **Windows 11** — PinPoint applies the border as a colored accent to the edge of the window's title bar using the native Windows composition layer. It can look subtle depending on your chosen color. Try a high-contrast color such as `#00FFFF` (cyan) to confirm it is working before settling on your preferred shade.
- **Windows 10** — PinPoint draws a framing overlay on top of the window. If the overlay looks distorted or misaligned, try resizing the pinned window slightly — this forces Windows to redraw the overlay and usually corrects alignment issues.

<Note>
  The border is purely visual. Pinning is controlled by the hotkey or the tray icon, not by the border setting.
</Note>

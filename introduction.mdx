PinPoint is a lightweight Windows tray utility from Automata Labs that keeps any window floating above every other window on your screen. This page explains what PinPoint does, the problem it solves, and the core features you'll use every day.

## The problem PinPoint solves

Windows doesn't make it easy to keep a window on top of everything else. The built-in Always-on-Top option is buried in title bar menus — and only some applications expose it at all. If you want to keep a calculator visible while you fill in a spreadsheet, or keep a reference document on top while you write, you're left hunting through menus or switching windows constantly.

PinPoint replaces that friction with a single keypress.

## How it works

The core workflow is three steps:

1. Click the window you want to keep on top.
2. Press your hotkey (default: **Alt+P**). A colored border appears around the window — it is now pinned Always-on-Top.
3. Press **Alt+P** again to unpin. The border disappears and the window returns to normal stacking order.

PinPoint runs in the background from the moment Windows starts. You never need to open it to use it.

## Key features

- **One-key pinning** — a global hotkey (default: Alt+P) pins or unpins the focused window instantly, from anywhere on your desktop
- **Visual border overlay** — a colored border appears around every pinned window so you always know which ones are on top; you can change the color and thickness in Settings
- **System tray icon** — the PinPoint tray icon gives you a live list of all pinned windows and lets you unpin any of them without touching the hotkey
- **Custom hotkey** — change the default Alt+P to any key combination you prefer, straight from Settings
- **Sound effects** — optional audio feedback plays when you pin or unpin a window; turned off by default
- **Themes and color presets** — choose light, dark, or system theme, and pick from multiple background color presets for the PinPoint UI
- **11 supported languages** — PinPoint is available in 11 languages including English, Spanish, Chinese, Japanese, and more
- **Auto-start with Windows** — PinPoint starts automatically when you log in so your hotkey is always ready; you can turn this off in Settings

## System requirements

PinPoint requires **Windows 10 or Windows 11** (64-bit). It is distributed as an MSI installer.

<Note>
  PinPoint is a Windows-only application. It is not available on macOS or Linux.
</Note>
